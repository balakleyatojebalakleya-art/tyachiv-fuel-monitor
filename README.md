# Пальне Тячів — Tyachiv Fuel Monitor

Вебсайт для порівняння цін на пальне на АЗС міста Тячів.

## Поточний стан

- `index.html` — адаптивна сторінка сайту з фільтрами за видом пального та підсумковими цінами.
- `data/prices.json` — файл даних, який сайт читає для відображення цін.
- Джерело для подальшого підключення: [Tanqo — ціни на пальне в Тячеві](https://tanqo.app/uk-ua/fuel-prices/tiachiv).

**Увага:** автоматичний збір ще не налаштований. Поки `data/prices.json` порожній, сайт не показує цін. Не вносьте неперевірені ціни як фактичні.

## Наступні кроки

1. Перевірити дозволений і стабільний спосіб отримання даних Tanqo (API або інший публічно дозволений канал).
2. Додати збір даних та перевірку структури/дати оновлення.
3. Налаштувати GitHub Actions за розкладом і зберігання історії цін.
4. Увімкнути GitHub Pages.
